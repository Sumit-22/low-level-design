# 7️⃣Proxy

## 🔥 Why It Exists

You want control over access.

Types:

- Lazy loading
- Access control
- Logging
- Remote proxy
- Virtual proxy

Example:

Database proxy that adds:

- Caching
- Authentication
- Retry logic

Before real DB call.

## When To Use

- Security layer
- Caching layer
- Lazy initialization
- Remote call wrapper

## When NOT To Use

- Direct simple call
- No cross-cutting concerns
